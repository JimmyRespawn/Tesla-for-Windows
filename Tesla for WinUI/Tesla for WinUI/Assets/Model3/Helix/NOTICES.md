# Helix 对比页面依赖

新页面使用 HelixToolkit.WinUI.SharpDX 和 HelixToolkit.SharpDX.Assimp 3.1.2，项目来源：https://github.com/helix-toolkit/helix-toolkit 。对应 MIT 许可见 `HelixToolkit-LICENSE.txt`。

模型导入使用 SharpAssimp 6.0.6，其托管包装及 Assimp 原生库的许可文字见 `SharpAssimp-LICENSE.txt`。依赖由 NuGet 提供，运行时无需下载模型或贴图。

Model 3 模型的 Ameer Studio / CC BY 4.0 署名与适配说明见上级目录 `CREDITS.md` 和 `MODEL-LICENSE.txt`。两个对比页面使用同一份 `model3.glb`。
