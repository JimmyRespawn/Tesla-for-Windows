# Public demo fixtures

These JSON files are sanitized examples for offline demo mode. Account names,
email, UUIDs, vehicle identifiers, VIN serials and coordinates are fictional.
VIN prefixes and model-year characters are retained solely to exercise vehicle
configuration and range selection; these fixtures must not be used for vehicle commands.
Tokens and driver public keys are empty. Coordinates use a generic San Francisco
demo point and do not represent a user's location.

Local originals, if present, are preserved in the repository's ignored
`.local/TestData.original/` directory for recovery. They are not packaged as assets.
